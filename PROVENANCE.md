# Provenance

This public repository was prepared on 2026-09-30 as a sanitized source export from the owner's private Yunkai DesktopBridge working tree.

The export includes selected bridge source code, tests, example configuration, and the small shared contract package needed to run it. It deliberately excludes machine/account bindings, real tunnel IDs, private runtime configuration, backups, caches, local reports/evidence, machine-specific DevSpace routing, and binary tunnel clients.

The public candidate was re-scanned after export for owner-specific paths, real tunnel IDs, common credential/token formats, cache/runtime artifacts, binaries, and accidental pagination/truncation markers.

Python packages listed in `requirements.txt` are dependencies installed separately and are not vendored here; they remain under their own licenses.

Optional OpenAI tunnel-client integration is external to this source repository and remains under the upstream project's license and NOTICE.
