# Provenance

This public repository was prepared on 2026-09-30 as a sanitized source export from the owner's private Yunkai DesktopBridge working tree.

The export includes selected bridge source code, tests, example configuration, and the small shared contract package needed to run it. It deliberately excludes machine/account bindings, real tunnel IDs, private runtime configuration, backups, caches, local reports/evidence, and binary tunnel clients.

Python packages listed in `requirements.txt` are dependencies installed separately and are not vendored here; they remain under their own licenses.

The private source tree did not contain upstream repository URLs or third-party source-license headers in the selected bridge files during the publication audit. This statement is a provenance note, not a warranty that external dependencies have the same license as this repository.
